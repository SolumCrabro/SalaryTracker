# 📱 Salary Tracker — Personal Finance & Debt Management App

**Salary Tracker** — это современное, легкое и интуитивно понятное Android-приложение для персонального финансового учета, контроля плановых доходов и управления накопительным долгом. 

Интерфейс приложения полностью спроектирован на Jetpack Compose силами декларативного UI (без использования тяжелых растровых изображений), поддерживает динамическую смену тем и плавные каскадные анимации.

## ✨ Ключевые фичи (Key Features)

* **🔄 Автоматический расчет накопительного долга:** Умный движок кодом переносит остатки задолженностей и профицита между месяцами. Приоритетно гасятся самые старые задолженности, выводя пользователя в актуальный статус «Переплаты» или долга.
* **🌓 Адаптивный UI (Светлая и Тёмная темы):** Интерфейс мгновенно переключается на лету. Тёмная тема выполнена в стиле глубокого графитового киберпанка, светлая — в пастельном журнальном минимализме с четкими контурными акцентами статусов.
* **📊 Интерактивная кодовая аналитика:** Круговые диаграммы структуры баланса (Donut Chart) и линейные графики динамики остатков (Line Chart) отрисованы чисто кодом через `Canvas`. Графики динамически адаптируются под тему и размеры экрана устройства.
* **⚡ Быстрый ввод в один тап:** Форма внесения средств оборудована удобной сеткой шаблонов частых сумм (`$100` — `$600`), избавляя от необходимости ручного ввода цифр с клавиатуры.
* **🎭 Плавный UX и каскадные анимации:** Элементы истории месяцев и списки транзакций выплывают на экран с мягким каскадным staggered-эффектом (`Animatable`), создавая ощущение премиального софта.
* **🗑️ Безопасное удаление по свайпу:** Реализован нативный жест Swipe-To-Dismiss для быстрого удаления ошибочных платежей с анимированным возвратом плашки на место при отмене в темном/светлом `AlertDialog`.

## 🛠️ Стек технологий (Tech Stack & Architecture)

Приложение написано в строгом соответствии с современными рекомендациями Google по архитектуре Android-приложений:

* **Language:** [Kotlin](https://kotlinlang.org) — 100% проекта.
* **UI Framework:** [Jetpack Compose](https://android.com) — декларативный интерфейс, кастомная отрисовка графиков через `Canvas`.
* **Architecture Pattern:** MVVM (Model-View-ViewModel) + Clean Architecture.
* **Local Database:** [Room Database](https://android.com) — надежное локальное хранилище транзакций с использованием компилятора **KSP (Kotlin Symbol Processing)** для ускорения сборки.
* **Key-Value Storage:** [Jetpack DataStore](https://android.com) — асинхронное сохранение параметров первого запуска (onboarding), окладов по умолчанию и глубины истории.
* **Asynchronous & Streams:** Kotlin Coroutines & StateFlow — для реактивного обновления графиков и таблиц в реальном времени при изменении данных.
* **Navigation:** Compose Navigation Components — безопасная трехэкранная навигация с парящим кастомным нижним меню.

## 🚀 Как собрать проект из исходников (Getting Started)

Если вы хотите изучить код или доработать проект под себя:
1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com](https://github.com/SolumCrabro/SalaryTracker.git)
   ```
2. Откройте проект в **Android Studio (Koala или новее)**.
3. Убедитесь, что в системе установлен JDK 17 или выше.
4. Дождитесь окончания синхронизации Gradle и сборки KSP-индексов.
5. Нажмите кнопку **Run** (`Shift + F10`) для запуска на эмуляторе.
